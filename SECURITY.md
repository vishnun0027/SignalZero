# Security Policy

## Supported Versions

SignalZero currently supports the latest main branch. As this is an early-stage project, please use the most recent commit.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within SignalZero, please report it via private email or through GitHub Security Advisories if available. Do not disclose the vulnerability in public issues. We will try to respond to all reports within 48 hours and release a patch as soon as possible.
